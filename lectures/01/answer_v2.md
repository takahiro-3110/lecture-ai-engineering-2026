## 宿題

- 取り組んだレベル：基礎
- 質問：「LoRAとは何ですか？」
- 実行条件：`AIE_MODEL=gemini-3.5-flash-lite` と `AIE_MODEL=gemini-3.8-flash` で、`uv run python -m app.ask "LoRAとは何ですか？"` を各8回実行した。実行順は `gemini-3.5-flash-lite` を8回、その後 `gemini-3.8-flash` を8回。temperature は指定せず、アプリ／モデルの既定値を使用した。実行日時は2026-10-31 14:30:32〜14:35:01 UTC。失敗時の再試行やモデル変更はしていない。
- 結果：
  - `gemini-3.5-flash-lite`：8回すべて成功。入力トークン数は各回7、出力トークン数は順に623、629、724、653、558、643、663、632（558〜724）。
  - `gemini-3.8-flash`：8回すべて失敗。各回とも503（モデルが混み合っている旨のエラー）で、回答は得られなかった。
  - 実行順・UTC日時・成否・回答またはエラーの詳細は [model_runs.jsonl](./model_runs.jsonl) の試行19〜34に記録した。今回の結果だけを比較対象とし、日時や実行順を確認できない過去の記録は回数に含めていない。
- 気づき・疑問：
  - 成功した `gemini-3.5-flash-lite` の8回答は、LoRAを「Low-Rank Adaptation（低ランク適応）」と説明し、ベースモデルの重みを固定して小さな追加パラメータ（アダプター／差分）を学習する効率的なファインチューニング手法とする点で共通していた。
  - 一方、説明の順序や比喩には揺れがあった。「付箋」「追加パーツ」「小さなネットワーク」などの表現、背景・仕組み・メリット・利用例の組み立て方が回答ごとに異なった。画像生成AIやLLMの利用例、コスト・学習時間・保存容量の説明も回答によって強調点や数値が違った。表現の違いだけでなく、数値や効果の説明もそのまま事実とみなさず確認が必要だと感じた。出力トークン数も558〜724と幅があった。
  - `gemini-3.8-flash` は今回8回とも回答が得られなかったため、今回の実行結果からモデル間の回答内容の違いは比較できない。確認できたのは、指定した実行環境では503が続いたことまでで、原因や今後の利用可否は未確認。別モデルへの切り替えは行っていない。
